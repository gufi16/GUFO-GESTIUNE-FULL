# Branding Gufo e-Factura

Pune aici fisierele de branding pentru installer:

- `gufo-efactura.ico`
- optional `gufo-efactura.png`

`gufo-efactura.ico` este folosit de scriptul Inno Setup:

- icon installer
- icon Start Menu
- icon uninstall

Logo-ul atasat in conversatie trebuie exportat in `.ico` si salvat aici inainte de build-ul final al installerului.
